# t03 - the lab's own two signatures, and nothing else
# db-custom holds only the signatures written for this lab: one pattern
# signature (.ndb) for a marker string the lab invented, and one whole-file
# hash signature (.hdb). ClamAV itself adds the .UNOFFICIAL ending to the
# names when it reports them - the mark of a signature that did not come
# from a signed official database. No real malware is involved anywhere.

16b9de69a4c99b6dca59fa252dc2c7ac:77:Lab.Sig.WholeFile
